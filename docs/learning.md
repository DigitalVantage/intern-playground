**About versions:** we use Next.js 16. Course 2 shows Next.js 15. The
differences that matter for a beginner are small. The biggest one is that
`params` in a page is now a promise you `await`. When something in a video does
not work the same here, check the official docs below, or ask.

## Subtitles in your language

All of the videos have automatic subtitles that YouTube can translate:

1. Start the video, click ⚙️ (**Settings**).
2. **Subtitles/CC** → **English (auto-generated)**.
3. ⚙️ again → **Subtitles/CC** → **Auto-translate** → your language.

The subtitles are automatic, so the translation is understandable but not
perfect. Listening to the English while reading your language is the best of
both.

## How to learn from a video

- **Type the code yourself**, do not copy it. Typing is where the questions
  come from.
- **Pause and predict:** before the instructor runs the code, say what you
  think will happen.
- **Change one thing** after each part: a colour, a text, a condition. See what
  breaks.
- Write down what you did not understand and bring it to the daily meeting.
