# Changelog

Every `feat` and `fix` pull request adds a line under `[Unreleased]`, in the
same pull request as the code.

## [Unreleased]

### Docs

- A working guide to Git and GitHub: taking issues, branches, rebasing,
  getting out of trouble, opening and reviewing pull requests, useful views.
- Conventions for commits, pull requests, the CHANGELOG, documentation and
  code comments.

### Added

- Onboarding issue template: a personal, ordered first-week checklist each
  intern opens for themselves.
- `.env.example` with the page title as the first variable, and a README section on
  how environment variables and secrets are handled.
- Intern playground: a Next.js app listing everyone who shipped a first pull
  request, with CI, hooks and the team's pull request process.
